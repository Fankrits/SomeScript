\section{Introduction}
Welcome to this simple \LaTeX{} document template. It is configured with clean geometry margins, standard article layout, and essential packages for scientific text and mathematical formulas.

\section{Mathematics Example}
You can include inline mathematical expressions like $E = mc^2$ or standalone, centered equations using the \texttt{equation} environment:

\begin{equation}
    f(x) = \int_{0}^{\infty} e^{-x^2} \, dx
\end{equation}

\section{Features Included}
\begin{itemize}
    \item Standard A4 layout with 1-inch margins.
    \item Native math support via \texttt{amsmath}.
    \item Document structure with automated title, sections, and lists.
\end{itemize}
