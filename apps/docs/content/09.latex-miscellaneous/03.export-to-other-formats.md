# Export To Other Formats

Strictly speaking, LaTeX source can be used to directly generate two formats:

- DVI using `latex`, the first one to be supported;
- PDF using `pdflatex`, more recent.

Using other software freely available on Internet, you can easily convert DVI and PDF to other document formats. In particular, you can obtain the PostScript version using software which is included in your LaTeX distribution. Some LaTeX IDE will give you the possibility to generate the PostScript version directly (even if it uses internally a DVI mid-step, e.g. LaTeX → DVI → PS). It is also possible to create PDF from DVI and vice versa. It doesn't seem logical to create a file with two steps when you can create it straight away, but some users might need it because the format you can generate depends upon the formats of the images you want to include (EPS for DVI, PNG and JPG for PDF).

Other formats can be produced, such as RTF (which can be used in Microsoft Word) and HTML. However, these documents are produced from software that parses and interprets the LaTeX files, and do not implement all the features available for the primary DVI and PDF outputs. Nonetheless, they do work, and can be crucial tools for collaboration with colleagues who do not edit documents with LaTeX.

## Tools installation

This section features a lot of third-party tools; most of them are installed independently of your TeX distribution.

Some tools are Unix-specific (*BSD, GNU/Linux and Mac OS X), but it may be possible to make them work on Windows. If you have the choice, it is often easier with Unix systems for command line tools.

Some tools may already be installed. For instance, you can check if dvipng is installed and ready to use (Unix only):

```bash
type dvipng
```

Most of these tools are installable using your package manager or portage tree (Unix only).

## Preview mode

This section describes how to generate a screenshot of a LaTeX page or of a specific part of the page using the LaTeX package preview. Screenshots are useful, for example, if you want to include a LaTeX generated formula on a presentation using your favorite slideware like Powerpoint, Keynote or LibreOffice Impress. First, start by making sure you have preview. See [Installing Extra Packages](/wiki/LaTeX/Installing_Extra_Packages).

Say you want to take a screenshot of a formula. Write this formula in the preview environment:

```latex
\documentclass{article}
\usepackage[active]{preview}
\begin{document}
\begin{preview}
\[
\pi = \sqrt{12}\sum^\infty_{k=0} \frac{ (-3)^{-k} }{ 2k+1 }
\]
\end{preview}
\end{document}
```

Note the active option in the package declaration and the preview environment around the equation's code. Without any of these two, you won't get any output.

This package is also very useful to export specific parts to other format, or to produce graphics (e.g. using [PGF/TikZ](/wiki/LaTeX/PGF/TikZ)) and then including them in other documents. You can also automate the previewing of specific environments:

```latex
\usepackage[active,tightpage]{preview}
\PreviewEnvironment{lstlisting}
\setlength{\PreviewBorder}{10pt}%

% ...

\begin{lstlisting}
int main()
{
        /* ... */
}
\end{lstlisting}
```

This will produce a PDF containing only the listing content; the *page* layout will depend on the shape of the source code.

## Convert to PDF

### Directly

```bash
pdflatex my_file
```

### DVI to PDF

```bash
dvipdfm my_file.dvi
```

will create my\_file.pdf. Another way is to pass through PS generation:

```bash
dvi2ps myfile.dvi
ps2pdf myfile.ps
```

you will get also a file called *my\_file.ps* that you can delete.

### Merging PDF

If you have created different PDF documents and you want to merge them into one single PDF file you can use the following command-line command. You need to have Ghostscript installed:

#### Using Windows

```bash
gswin32 -dNOPAUSE -sDEVICE=pdfwrite -sOUTPUTFILE=Merged.pdf -dBATCH 1.pdf 2.pdf 3.pdf
```

#### Using Linux

```bash
gs -dNOPAUSE -sDEVICE=pdfwrite -sOUTPUTFILE=Merged.pdf -dBATCH 1.pdf 2.pdf 3.pdf
```

Alternatively, [PDF-Shuffler](http://pdfshuffler.sourceforge.net/) is a small python-gtk application, which helps the user to merge or split pdf documents and rotate, crop and rearrange their pages using an interactive and intuitive graphical interface. This program may be available in your Linux distribution's repository.

Another option to check out is [pdftk](http://www.accesspdf.com/) (or PDF toolkit), which is a command-line tool that can manipulate PDFs in many ways. To merge one or more files, use:

```bash
pdftk 1.pdf 2.pdf 3.pdf cat output 123.pdf
```

#### Using pdfLaTeX

*Note:* If you are merging external PDF documents into a LaTeX document which is compiled with `pdflatex`, a much simpler option is to use the pdfpages package, e.g.:

```latex
\usepackage{pdfpages}
...
\includepdf[pages=-]{Document1.pdf}
\includepdf[pages=-]{Document2.pdf}
...
```

Three simple shell scripts using the pdfpages package are provided in the [pdfjam bundle](http://www2.warwick.ac.uk/fac/sci/statistics/staff/academic/firth/software/pdfjam) by D. Firth. They include options to merge several pdf files (pdfjoin), put several pages in one physical sheet (pdfnup) and rotate pages (pdf90).

See also [Modular Documents](/wiki/LaTeX/Modular_Documents#Inserting_PDF_files)

### XeTeX

You can also use XeTeX (or, more precisely, XeLaTeX), which works in the same way as pdflatex: it creates a PDF file directly from LaTeX source. One advantage of XeTeX over standard LaTeX is support for Unicode and modern typographic technologies such as TrueType/OpenType fonts. See [its Wikipedia entry](https://en.wikipedia.org/wiki/XeTeX) for more details.

Customization of PDF output in XeTeX (setting document title, author, keywords etc.) is done using the configuration of [hyperref](/wiki/LaTeX/Hyperlinks#Customization) package.

## Convert to PostScript

from PDF:

```bash
pdf2ps my_file.pdf
```

from DVI:

```bash
dvi2ps my_file.dvi
```

## Convert to RTF

LaTeX can be converted into an RTF file, which in turn can be opened by a word processor such as [LibreOffice Writer](https://en.wikipedia.org/wiki/LibreOffice_Writer) or [Microsoft Word](https://en.wikipedia.org/wiki/Microsoft_Word). This conversion is done through [latex2rtf](https://github.com/latex2rtf/latex2rtf), which may run on any computer platform. The program operates by reading the LaTeX source, and mimicking the behaviour of the LaTeX program. `latex2rtf` supports most of the standard implementations of LaTeX, such as standard formatting, some math typesetting, inclusion of EPS, PNG or JPG graphics, and tables.

latex2rtf is simple to use. The command-line version can be used on an example mypaper.tex file:

```bash
latex mypaper
bibtex mypaper       # if you use bibtex
latex2rtf mypaper
```

Both `latex` and (if needed) `bibtex` commands need to be run *before* `latex2rtf`, because the .aux and .bbl files are needed to produce the proper output. The result of this conversion will create myfile.rtf, which you may open in many word processors such as Microsoft Word or LibreOffice.

## Convert to HTML

There are many converters to HTML. Some of them use an intermediate file which then will be converted to the destination format.

**HEVEA:**

```bash
hevea mylatexfile
```

**latex2html:**

```bash
latex2html -html_version 4.0,latin1,unicode -split 1 -nonnavigation -noinfo -title "MyDocument" MyDocument.tex
```

**LaTeXML:**

```bash
latexmlc paper.tex --destination=paper.html
```

**pdf2htmlEX:**

```bash
pdf2htmlEX [options] <input.pdf> [<output.html>]
```

pdf2htmlEX can convert PDF to HTML without losing text or format. It is designed as a general PDF to HTML converter, not only restricted to the PDF generated by LaTeX source. LaTeX users can compile the LaTeX source code to PDF, and then convert the PDF to HTML via pdf2htmlEX.

**TeX4ht:**

[TeX4ht](http://tug.org/tex4ht/) has many options and possible configurations, but for a basic conversion:

```bash
htlatex myfile.tex
```

will usually result in a reasonable HTML approximation.

**bibtex2html:**

For exporting the BibTeX file only.

```bash
bibtex2html mybibtexfile
```

## Convert to image formats

It is sometimes useful to convert LaTeX output to image formats for use in systems that do not support DVI nor PDF files, such as Wikipedia.

There are two families of graphics:

- **Vector graphics** can be scaled to any size, thus do not suffer from quality loss. SVG is a vector format.
- **Raster graphics** define every pixel explicitly. PNG is a raster format.

So vector graphics are usually preferred. There are still some cases where raster graphics are used:

- The target system does not handle vector graphics, only raster graphics are supported.
- SVG cannot embed fonts. So either the font will be rendered using a local .ttf or .otf font (which will mostly change the output), or all characters must be turned to vector graphics. This last method makes the SVG big and slow. If the input LaTeX file contains a lot of text which formatting must be preserved, SVG is not that great.

So SVG is great for drawings and a small amount of text. JPG is a well known raster format, however it is usually not as good as PNG for text.

### Multiple formats

**pdftocairo** is featured in the poppler toolset:

```bash
pdftocairo -svg latexdoc.pdf output.svg
```

pdftocairo also supports various raster graphic formats.

### Vector graphics

**pdf2svg** — Direct conversion from PDF to SVG:

```bash
pdf2svg file.pdf file.svg
```

**dvisvgm** — converts from DVI to SVG:

```bash
dvisvgm -n file.dvi
```

**Inkscape** — able to convert to SVG, PDF, EPS, and other vector graphic formats:

```bash
inkscape --export-area-drawing --export-ps=OUTPUT INPUT
inkscape --export-area-page --export-plain-svg=OUTPUT INPUT
```

### Raster graphics

- **JPEG** — Run ghostscript on the PostScript file created by pdf2ps:
    ```bash
    echo "quit" | gs -sDEVICE=jpeg -sOutputFile=document.jpg -r300 document.ps
    ```

    MacOS: MacTeX distribution comes with handy cli for "printing":
    ```bash
    pdftoppm yourpdf.pdf -progress -jpeg yourpdf.jpg
    ```

- **GIMP** — Open your file with GIMP. It will ask you which page you want to convert, whether you want to use anti-aliasing (choose *strong* if you want to get something similar to what you see on the screen). Try different resolutions to fit your needs, but 100 dpi should be enough.

- **dvipng** — A method for DVI files. You need to convert font size in pixels to dots per inch (dpi). The formula is: `<dpi> = <font_px>*72.27/10`. To generate the desired png file run:
    ```bash
    dvipng -T tight -D 231.26 -o foo.png foo.dvi
    ```

- **ImageMagick** — The convert command can convert both DVI and PDF files to PNG:
    ```bash
    convert input.pdf output.png
    ```

## Convert to plain text

If you are thinking of converting to plain text for spell-checking or to count words, there may be an easier way — read Tips and Tricks first. Following are available tools:

- **detex** — comes with latex distribution. Most LaTeX distributions come with detex program, which strips LaTeX commands. It can handle multi-file projects:
    ```bash
    detex yourfile
    ```
    *(note the omission of .tex extension)*. Outputs result to the standard output. Redirect output to file using:
    ```bash
    detex yourfile > yourfile.txt
    ```

- **catdvi** — If you want to keep the formatting, you can use a DVI-to-plain text converter:
    ```bash
    catdvi yourfile.dvi | fmt -u
    ```
    The use of `fmt -u` will remove the justification.
