# Command Glossary

This is a glossary of LaTeX commands — an alphabetical listing of LaTeX commands with the summaries of their effects. (Brackets "[]" are optional arguments and braces "{}" are required arguments.)

## # (Symbols)

`\`

see [slash marks](/document-fundamentals/paragraph-formatting#Slash_marks)

`\@`

following period ends sentence

`\\*[extra-space]`

new line

`\,`

thin space, math and text mode

`\;`

thick space, math mode

`\:`

medium space, math mode

`\!`

negative thin space, math mode

`\-`

hyphenation; tabbing

`\=`

set tab, see tabbing

`\>`

tab, see tabbing

`\<`

back tab, see tabbing

`\+`

see tabbing

\'`

accent or tabbing

\``

accent or tabbing

`\|`

double vertical lines, math mode

`\(start math environment`

`\)`

end math environment

`\[`

begin displaymath environment

`\]`

end displaymath environment

## A

`\addcontentsline{file}{sec_unit}{entry}`

adds an entry to the specified list or table

`\addtocontents{file}{text}`

adds text (or formatting commands) directly to the file that generates the specified list or table

`\addtocounter{counter}{value}`

increments the counter

`\address{Return address}`

`\addtolength{len-cmd}{len}`

increments a length command, see [Length](/reference/lengths)

`\addvspace`

adds a vertical space of a specified height

`\alph`

causes the current value of a specified counter to be printed in alphabetic characters

`\appendix`

changes the way sectional units are numbered so that information after the command is considered part of the appendix

`\arabic`

causes the current value of a specified counter to be printed in Arabic numbers

`\author`

declares the author(s). See [Document Structure](/document-fundamentals/document-structure#Top_Matter)

## B

`\backslash`

prints a backslash

`\baselineskip`

a length command (see [Lengths](/reference/lengths)), which specifies the minimum space between the bottom of two successive lines in a paragraph

`\baselinestretch`

scales the value of `\baselineskip`

`\bfseries`

Boldface typeface

`\bibitem`

generates a labeled entry for [the bibliography](/document-fundamentals/document-structure#The_Bibliography)

`\bigskipamount`

`\bigskip`

equivalent to `\vspace{\bigskipamount}`

`\boldmath`

bold font in math mode

`\boldsymbol`

bold font for symbols

## C

`\cal`

Calligraphic style in math mode

`\caption`

generate caption for figures and tables

`\cdots`

Centered dots

`\centering`

Used to center align LaTeX environments

`\chapter`

Starts a new chapter. See [Document Structure](/document-fundamentals/document-structure#Sectioning_Commands).

`\circle`

`\cite`

Used to [make citations](/technical-writing/bibliography-management#Citations) from the provided bibliography

`\cleardoublepage`

`\clearpage`

Ends the current page and causes any floats to be printed. See [Page Layout](/page-design/page-layout#Manual_page_formatting).

`\cline`

Adds horizontal line in a table that spans only to a range of cells. See `\hline` and [Tables](/tables-and-graphics/tables) chapter.

`\closing`

Inserts a closing phrase (e.g. `\closing{yours sincerely}`), leaves space for a handwritten signature and inserts a signature specified by `\signature{}`. Used in the *Letter* class.

`\color`

Specifies color of the text. See [LaTeX/Colors](/document-fundamentals/colors)

`\copyright`

makes © sign. See [Formatting](/document-fundamentals/paragraph-formatting#Other_symbols).

## D

`\dashbox`

`\date`

`\ddots`

Inserts a diagonal ellipsis (3 diagonal dots) in math mode

`\documentclass[options]{style}`

Used to begin a LaTeX document

`\dotfill`

`\dfrac`

## E

`\em`

Toggles italics on/off for the text inside curly braces with the command. Such as `{\em This is in italics \em but this isn't \em and this is again}`. This command allows nesting.

`\emph`

Toggles italics on/off for the text in curly braces following the command e.g. `\emph{This is in italics \emph{but this isn't} and this is again}`.

`\ensuremath` (LaTeX2e)

Treats everything inside the curly braces as if it were in a math environment. Useful when creating commands in the preamble as they will work inside or out of math environments.

`\epigraph`

Adds an epigraph. Requires epigraph package.

`\euro`

Prints euro € symbol. Requires eurosym package.

## F

`\fbox`

`\flushbottom`

`\fnsymbol`

`\footnote`

Creates a [footnote](/page-design/footnotes-and-margin-notes#Footnotes).

`\footnotemark`

`\footnotesize`

Sets font size. See [Text Formatting](/document-fundamentals/text-formatting#Sizing_text).

`\footnotetext`

`\frac`

inserts a fraction in mathematics mode. The usage is `\frac{numerator}{denominator}`.

`\frame`

`\framebox`

Like `\makebox` but creates a frame around the box. See [Boxes](/reference/boxes).

`\frenchspacing`

Instructs LaTeX to abstain from inserting more space after a period (`.`) than is the case for an ordinary character. In order to untoggle this functionality resort to the command `\nonfrenchspacing`.

## G

(no entries)

## H

`\hfill`

Abbreviation for `\hspace{\fill}`.

`\hline`

adds a horizontal line in a tabular environment. See also `\cline`, [Tables](/tables-and-graphics/tables) chapter.

`\href`

Add a link, or an anchor. See [Hyperlinks](/cross-references/hyperlinks)

`\hrulefill`

`\hspace`

Produces horizontal space.

`\huge`

Sets font size. See [Text Formatting](/document-fundamentals/text-formatting#Sizing_text).

`\Huge`

Sets font size. See [Text Formatting](/document-fundamentals/text-formatting#Sizing_text).

`\hyphenation{word list}`

Overrides default hyphenation algorithm for specified words. See [Hyphenation](/document-fundamentals/text-formatting#Hyphenation)

## I

`\include`

This command is different from `\input` in that it's the output that is added instead of the commands from the other files. For more see [LaTeX/Basics](/getting-started/basics#Big_Projects)

`\includegraphics`

Inserts an [image](/tables-and-graphics/importing-graphics#The_graphicx_package). Requires graphicx package.

`\includeonly`

`\indent`

`\input`

Used to read in LaTeX files. For more see [LaTeX/Basics](/getting-started/basics#Big_Projects).

`\itshape`

Italicizes the text which is inside curly braces with the command. Such as `{\itshape This is in italics}`. `\em` is generally preferred since it allows nesting.

`\item`

Creates an item in a list. Used in [list structures](/document-fundamentals/list-structures).

## K

`\kill`

Prevent a line in the tabbing environment from being printed.

`\LaTeXe`

`\ldots`

`\left`

`\noindent`

`\nonfrenchspacing`

`\nopagebreak`

`\parbox`

`\parindent`

`\parskip`
