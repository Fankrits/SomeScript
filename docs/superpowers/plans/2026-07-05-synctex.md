# Bidirectional SyncTeX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement bidirectional SyncTeX synchronization between the CodeMirror editor and the PDF viewer so cursor movement scrolls the PDF and double-clicking the PDF focuses the code.

**Architecture:** Appends `--synctex` to tectonic, adds a `/synctex` endpoint in the compiler service to parse the gzipped text into lightweight JSON coordinate bounding boxes, and integrates forward/backward lookup logic in the Next.js frontend using the `@embedpdf` APIs.

**Tech Stack:** Next.js (editor), Bun (compiler), tectonic, react-pdf-viewer.

## Global Constraints

- Never install unneeded npm dependencies; parse `.synctex.gz` natively using `Bun.gunzipSync` and simple regex line-by-line parsing.
- Always validate types using `bun x tsc --noEmit` inside `apps/editor/` after modifying page/component files.
- Mark intentional simplifications with a `// ponytail:` comment.

### Task 2: Implement SyncTeX Parser and /synctex Endpoint

**Files:**
- Modify: `apps/compiler/index.ts` (Add parser helper and API route)

**Interfaces:**
- Produces: `POST /synctex` endpoint returning parsed SyncTeX coordinates payload.

- [ ] **Step 1: Write SyncTeX Parser Helper**
  Add the `parseSyncTex` function to `apps/compiler/index.ts`:
  ```typescript
  interface SyncTexData {
    files: Record<string, string>;
    records: Array<{
      fileId: number;
      line: number;
      page: number;
      x: number;
      y: number;
      w: number;
      h: number;
    }>;
  }

  function parseSyncTex(rawText: string): SyncTexData {
    const files: Record<string, string> = {};
    const records: SyncTexData["records"] = [];
    let currentPage = 1;

    const lines = rawText.split(/\r?\n/);
    for (const line of lines) {
      if (line.startsWith("Input:")) {
        const parts = line.split(":");
        if (parts.length >= 3) {
          files[parts[1]] = parts.slice(2).join(":");
        }
      } else if (line.startsWith("{")) {
        currentPage = parseInt(line.substring(1), 10);
      } else if (line.startsWith("h") || line.startsWith("v") || line.startsWith("[")) {
        const content = line.substring(1);
        const parts = content.split(",");
        if (parts.length >= 6) {
          const fileId = parseInt(parts[0], 10);
          const lineNum = parseInt(parts[1], 10);
          const x = parseFloat(parts[2]);
          const y = parseFloat(parts[3]);
          const w = parseFloat(parts[4]);
          const h = parseFloat(parts[5]);
          
          if (!isNaN(fileId) && !isNaN(lineNum)) {
            records.push({ fileId, line: lineNum, page: currentPage, x, y, w, h });
          }
        }
      }
    }

    // ponytail: Deduplicate line records to keep payload small
    const seen = new Set<string>();
    const uniqueRecords = records.filter(r => {
      const key = `${r.fileId}:${r.line}:${r.page}`;
      if (seen.has(key)) return false;
      seen.add(key);
      return true;
    });

    return { files, records: uniqueRecords };
  }
  ```

      const fileBuffer = await fs.readFile(synctexPath);

      const text = new TextDecoder().decode(decompressed);
      const parsedData = parseSyncTex(text);

      return Response.json(parsedData);
    } catch (err: any) {
      return Response.json({ error: err.message }, { status: 500 });
    }

### Task 3: Create Next.js API route `/api/synctex`

**Files:**
- Create: `apps/editor/app/api/synctex/route.ts`

**Interfaces:**
- Consumes: Compiler's `/synctex` POST API.
- Produces: `POST /api/synctex` Next.js endpoint.

- [ ] **Step 1: Write Next.js API handler**
  Create the endpoint `/api/synctex/route.ts`:
  ```typescript
  import { getProjectPath, getProjectIdFromPath } from "@/lib/project";
  import { NextRequest } from "next/server";

  export async function POST(req: NextRequest) {
    try {
      const { path: fileRelativePath } = await req.json();
      if (!fileRelativePath) {
        return Response.json({ error: "Path parameter is required" }, { status: 400 });
      }

      const projectPath = await getProjectPath();
      const projectId = getProjectIdFromPath(projectPath);

      const compilerUrl = process.env.COMPILER_URL || "http://127.0.0.1:3001";
      const defaultMode =
        compilerUrl.includes("localhost") ||
        compilerUrl.includes("127.0.0.1") ||
        compilerUrl.includes("0.0.0.0")
          ? "local"
          : "upload";
      const compilerMode = process.env.COMPILER_MODE || defaultMode;

      const response = await fetch(`${compilerUrl}/synctex`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          mode: compilerMode,
          localProjectPath: projectPath,
          projectId,
          fileRelativePath,
        }),
      });

      if (!response.ok) {
        return Response.json({ error: "Failed to parse SyncTeX from compiler" }, { status: response.status });
      }

      const data = await response.json();
      return Response.json(data);
    } catch (error: any) {
      return Response.json({ error: error.message }, { status: 500 });
    }
  }
  ```
